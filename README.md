ArtichokePy was designed as a library to work with graphs in Python.

In the current state of development it can render graphs, run search algorithms, and persist graphs in CSV and JSON files.

Currently the project has been stopped for a long time and I think it will continue like this for a long time, that's why I decided to release it.

In this repository you will find the code such as unit tests (pytest) that guarantee that the project does not break.

If you find it useful, use it, or even better, modify it, just remember to **make public any changes you make**.

**ArtichokePy was always intended as a project by a student for other students, and knowledge always has to be free.**

> Gerardo Jovel
